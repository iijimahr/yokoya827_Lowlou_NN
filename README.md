# Lowlou_NN

PINN で非線形フォースフリー磁場を再構成するコードです。
下端（光球面）の磁場 B = (Bx, By, Bz) だけを境界条件として与え、フォースフリー条件 J×B = 0 と div B = 0 を満たす 3 次元の磁場を求めます。
テスト問題として Low & Lou の解析解（`input/b_0.210_0.124.npz`、64³）を使い、厳密解と比べて評価します。

## データの形式

npz の `"b"` に shape `(nx, ny, nz, 3)` の配列を入れます。`b[ix, iy, iz] = (Bx, By, Bz)` で、`iz = 0` が下端です。

## 手法

### ベースライン

1. **無次元化**: 長さは水平方向の領域の大きさ、磁場は下端の |B| の RMS で割ります。
2. **境界条件は下端だけ**: 側面と上端には何も課しません。
3. **損失**（どの項も B について 2 次）:
   - フォースフリー: |J×B|² / |B|²
   - div B: (∇·B)²
   - 下端境界: |B − B_obs|²（重み 10）
4. **内部の点は下端付近に多く取る**: 下端と上端の密度比は 10:1 です。
5. **学習率**: 1e-3 から 1e-5 まで、単調に下げます。
6. **ネットワーク**: 全結合 5 層 × 128、活性化関数 tanh。

### ベクトルポテンシャル + SIREN

ベースラインとの違いは 2 つです。

- **ベクトルポテンシャル**: ネットワークが A を出力し、B = ∇×A とします。div B = 0 が厳密に成り立つので、div B の損失はありません。計算時間は約 10 倍、GPU メモリは約 20 GB かかります。
- **SIREN**: 活性化関数を sin(3 ·) にします。

## 評価指標

| 指標 | 意味 | 完全一致 |
| --- | --- | --- |
| C_vec | ベクトル相関 | 1 |
| C_CS | 各点の向きの一致度 | 1 |
| E_n' | 1 − 誤差の合計 / 磁場の合計 | 1 |
| E_m' | 1 − 各点の相対誤差の平均 | 1 |
| energy | 磁気エネルギーの比 | 1 |
| E_n_bottom | 下端での誤差 | 0 |
| div_rel | div B の大きさ | 0（厳密解でも差分の誤差で 0.012） |
| sigma_J | 電流と磁場のなす角 | 0（厳密解でも差分の誤差で 0.025） |
