# Lowlou_NN

PINN で非線形フォースフリー磁場を再構成するコードです。
下端（光球面）の磁場 B = (Bx, By, Bz) だけを境界条件として与え、フォースフリー条件 J×B = 0 と div B = 0 を満たす 3 次元の磁場を求めます。
テスト問題として Low & Lou の解析解（`input/b_0.210_0.124.npz`、64³）を使い、厳密解と比べて評価します。

## ディレクトリ構成

```text
Lowlou_NN/
├── input/                        # 入力データ（Low & Lou の解析解）
├── lowlou/                       # 共通ライブラリ
│   ├── io.py                     #   データの読み書き
│   ├── metrics.py                #   厳密解との比較
│   └── viz.py                    #   図（磁場の断面、学習の経過）
├── results/                      # 実験ごとに 1 ディレクトリ
│   └── <日付>_<実験名>/
│       ├── train.py              #   学習スクリプト（手法のすべてが書いてある）
│       └── run.sh                #   学習して図を描く
└── note/                         # 実験の記録
    └── <日付>.md
```

## 準備

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install numpy matplotlib torch
pip install -e .
```

PyTorch は GPU ドライバの CUDA バージョンに合ったものを入れてください（CUDA 12.x なら `pip install torch==2.8.0`）。

## 研究の進め方

1. **実験ディレクトリを作る**: 元にする実験から `train.py` と `run.sh` をコピーします。名前は `<日付>_<実験名>` にします。

   ```bash
   mkdir results/2026-10-12_my_idea
   cp results/2026-10-05_baseline/{train.py,run.sh} results/2026-10-12_my_idea/
   ```

2. **`train.py` を書き換える**: 設定は先頭にまとめてあります。変えたことは、先頭の説明（docstring）にも書いておきます。
3. **実行する**: 学習して、結果の図を描きます。出力はすべて実験ディレクトリに書かれます。

   ```bash
   ./results/2026-10-12_my_idea/run.sh                 # 設定どおりのステップ数
   ./results/2026-10-12_my_idea/run.sh --steps 1000    # 短く試すとき
   ```

4. **結果を見る**: `loss.png`（学習の経過）、`slice_*.png`（断面）、`result.json`（最後の評価値）を見ます。
5. **記録する**: `note/<日付>.md` に書きます（下の「記録の付け方」）。
6. **コミットする**: `train.py`、`run.sh`、`note/` をコミットします。出力（モデル、予測、図、ログ）は大きいので git 管理外です。

## 記録の付け方

実験をしたら、`note/<日付>.md` に記録します。同じ日に複数の話題があるときは `note/<日付>_<話題>.md` にします。
後から読んで「何を試して、どうだったか」がわかるように、次のことを書きます。

```markdown
# 2026-10-12: ○○を試す

## 目的
何を確かめたいか。

## やったこと
- 実験: results/2026-10-12_my_idea（results/2026-10-05_baseline からの変更: ○○）
- 実行環境: GPU の種類

## 結果
| 実験 | ステップ数 | 実行時間 | E_n' | C_CS | sigma_J | div_rel |
| --- | --- | --- | --- | --- | --- | --- |

## わかったこと
## 次にやること
```

- 比べるときは、**実行時間もそろえて**比べます（1 ステップの重さが手法で違うため）。
- 数値は `result.json` から写します。
- 大事な図は `note/` にコピーして、ノートから参照します（`results/` の図は git 管理外です）。

## 出力ファイル

| ファイル | 内容 |
| --- | --- |
| `log.jsonl` | 損失（100 ステップごと） |
| `evals.jsonl` | 厳密解との比較（途中の評価） |
| `result.json` | 最後の評価値と実行時間 |
| `model.pt` | 学習したモデル |
| `B_pred.npz` | 格子点上の予測（データと同じ形式） |
| `loss.png` | 損失と評価値の時間変化 |
| `slice_z0.png`, `slice_y32.png` | 断面（予測・厳密解・差） |

## データの形式

npz の `"b"` に shape `(nx, ny, nz, 3)` の配列を入れます。`b[ix, iy, iz] = (Bx, By, Bz)` で、`iz = 0` が下端です。

## 評価指標

| 指標 | 意味 | 完全一致 |
| --- | --- | --- |
| C_vec | ベクトル相関 | 1 |
| C_CS | 各点の向きの一致度 | 1 |
| E_n' | 1 − 誤差の合計 / 磁場の合計 | 1 |
| E_m' | 1 − 各点の相対誤差の平均 | 1 |
| energy | 磁気エネルギーの比 | 1 |
| E_n_bottom | 下端での誤差 | 0 |
| div_rel | div B の大きさ | 0（厳密解でも差分の誤差で 0.012） |
| sigma_J | 電流と磁場のなす角 | 0（厳密解でも差分の誤差で 0.025） |
